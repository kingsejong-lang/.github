# kingsejong-lang/.github

KingSejong 조직의 공통 설정 저장소입니다.

| 파일 | 역할 |
|---|---|
| `profile/README.md` | [조직 페이지](https://github.com/kingsejong-lang)에 보이는 소개 |
| `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md` | 자기 파일이 없는 저장소에 기본으로 쓰이는 커뮤니티 문서 |
| `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` | 자기 템플릿이 없는 저장소에 기본으로 쓰이는 이슈·PR 양식 |

저장소에 같은 종류의 파일이 있으면 그 저장소의 파일이 우선합니다.
